# Trabajo Práctico: Seguridad
## Parte 1: Cuestionario de Investigación (Teoria)

1. La encriptación en la seguridad informática garantiza que los datos sean confidenciales y protegidos
   
2. **Encriptación en tránsito:** Protege los datos mientras viajan por la red (como por ejemplo: cuando viajan desde la aplicación hasta el servidor de la base de datos). <br> **Encriptación a nivel de columna / campo:** Cifra datos específicos muy sensibles (como contraseñas o números de tarjetas de crédito), mientras que el resto de la información se mantiene normal. <br> **Encriptación a nivel de tabla / espacio de tablas:** Cifra tablas enteras o grupos de archivos dentro del almacenamiento para que nadie pueda leerlos directamente desde el disco. <br> **Encriptación transparente de datos (TDE) / a nivel de disco:** Cifra toda la base de datos automáticamente en el almacenamiento físico. Las aplicaciones y los usuarios autorizados siguen consultando los datos con normalidad, pero si alguien roba el disco físico o hace una copia de respaldo de la base de datos, no podrá leer nada sin la clave del servidor.
